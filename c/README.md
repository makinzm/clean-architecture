# How to build

```bash
gcc -o main.out src/main.c
```

# How to find libraries


Search Web Search for what you want to implement, and add "C Library".

And if you find a library, you can check its manual page by using the `man` command in the terminal:

```bash
man <section_number> <library_name>
```

## Section Number

1. User commands
2. System calls
3. Library functions
